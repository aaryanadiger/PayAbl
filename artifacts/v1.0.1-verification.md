# PayAbl v1.0.1 — 22 October 2026

This release consolidates Ask PayAbl, deterministic navigation commands,
numbered contacts and safe name suggestions, explicit payment review,
700 ms hold-0 activation on contacts/amount/review, and count-only demo
PIN practice with microphone access disabled. Payments remain simulated.

The latest follow-ups verify TTS silence before starting recognition,
reset contact search on re-entry, suppress stale import announcements,
remove per-digit app speech and automatic phone-number reading on amount
entry, and use native Android haptic effects with a failure fallback.

App/package version: 1.0.1. Android versionCode: 3. iOS buildNumber: 3.
Existing Expo SDK 57 patch updates and the dependency lockfile are included.
The passive 3D-printed stencil requirement and existing keypad geometry remain.

Validation: npm run lint, npm run typecheck, npm test (21 tests),
git diff --check. Native audio, system TalkBack behavior, vibration and
physical stencil fit still require testing on the installed phone build.
Earlier verification reports describe intermediate states; use the current
handover and source for final behavior. No provider-owned PIN authentication
or live money transfer is implemented.
